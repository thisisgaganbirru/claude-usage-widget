# Claude Usage Widget v1.0.3

A lightweight Windows desktop widget for real-time Claude API usage
monitoring, living quietly in your system tray.

### What's Fixed in v1.0.3

- Refactored IPC channel usage to shared constants across main/preload/renderer
- Hardened preload channel allowlists with validated channel contracts from main
- Improved usage fetcher error classification and reliability handling paths
- Updated renderer bundling target for `nodeIntegration: false` environments
- Added typecheck-first quality guardrails in project scripts and CI workflow

### Features

- Real-time 5-hour session usage with live countdown timer
- 7-day rolling usage breakdown
- Per-model tracking — Opus, Sonnet, Haiku
- Three widget sizes: Small, Medium, Large
- Pin to always-on-top
- Click-through transparent areas — interact with apps behind the widget
- Persisted session across restarts

### Installation

1. Download `ClaudeUsageWidgetSetup.exe` below
2. Run the installer
3. Windows may show a SmartScreen warning — click **More info → Run anyway**
4. The widget will appear in your system tray

### Requirements

- Windows 10 / 11 (64-bit)
- A claude.ai account
