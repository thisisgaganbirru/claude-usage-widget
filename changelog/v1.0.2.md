# Claude Usage Widget v1.0.2

A lightweight Windows desktop widget for real-time Claude API usage  
 monitoring, living quietly in your system tray.

### What's Fixed in v1.0.2

- Fixed login window hidden behind always-on-top widget (was invisible  
  after clicking Login)
- Fixed login detection not firing after Google OAuth — Claude's SPA  
  navigation skips standard redirect events
- Fixed corrupted session store crash on reinstall (wrong encryption  
  key)
- Fixed React not loading on startup (`__dirname` error in renderer  
  bundle)
- Fixed `/auth/callback` being incorrectly blocked during Google OAuth  
  flow
- DevTools no longer opens in production builds
- Footer version now shows actual app version instead of hardcoded v1.0

### Features

- Real-time 5-hour session usage with live countdown timer
- 7-day rolling usage breakdown
- Per-model tracking — Opus, Sonnet, Haiku
- Three widget sizes: Small, Medium, Large
- Pin to always-on-top
- Click-through transparent areas — interact with apps behind the widget
- Persisted session across restarts

### Installation

1. Download `ClaudeUsageWidgetSetup.exe` below
2. Run the installer
3. Windows may show a SmartScreen warning — click **More info → Run  
   anyway** (app is open source, code is reviewable)
4. The widget will appear in your system tray

### Requirements

- Windows 10 / 11 (64-bit)
- A claude.ai account
