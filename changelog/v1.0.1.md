# Claude Usage Widget v1.0.1

A lightweight Windows desktop widget for real-time Claude API usage monitoring, living quietly in your system tray.

## What's New in v1.0.1

- Fixed fresh install session detection and state initialization errors
- Fixed login button click passthrough on transparent overlay issues
- Login window now opens centered on screen
- Enforced Node.js LTS engine requirements (18.x / 20.x / 22.x)

### Features

- Real-time 5-hour session usage with live countdown timer
- 7-day rolling usage breakdown
- Per-model tracking — Opus, Sonnet, Haiku
- Three widget sizes: Small, Medium, Large
- Pin to always-on-top
- Click-through transparent areas — interact with apps behind the widget
- Persisted session across restarts

### Installation

1. Download `ClaudeUsageWidgetSetup.exe` below
2. Run the installer
3. Windows may show a SmartScreen warning — click **More info → Run anyway** (app is open source, code is reviewable)
4. The widget will appear in your system tray

### Requirements

- Windows 10 / 11 (64-bit)
- A claude.ai account
