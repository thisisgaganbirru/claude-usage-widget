# Claude Usage Widget v1.0.4

A lightweight Windows desktop widget for real-time Claude API usage
monitoring, living quietly in your system tray.

### What's New in v1.0.4

- **Enhanced Widget Views**: Added AlertBanner component with dynamic notification thresholds
- **Settings Panel**: New dedicated settings interface with Tailwind-styled UI
- **IPC Architecture Refactor**: Improved preload security layer and channel definitions alignment
- **Auth Flow Improvements**: Better login window integration and session handling
- **Core Service Updates**: Refined usage poller, settings manager, and type definitions
- **Build & CI**: Updated Forge and Webpack configs; enforced quality checks on main/dev branches
- **Lint Tooling**: Added lint-guards.mjs for automated code quality validation

### Features

- Real-time 5-hour session usage with live countdown timer
- 7-day rolling usage breakdown
- Per-model tracking — Opus, Sonnet, Haiku
- Three widget sizes: Small (350×80), Medium (350×345), Large (350×650)
- Settings panel with customizable alert thresholds
- Alert banner for threshold notifications
- Pin to always-on-top
- Click-through transparent areas — interact with apps behind the widget
- Persisted session and settings across restarts

### Installation

1. Download `ClaudeUsageWidgetSetup.exe` below
2. Run the installer
3. Windows may show a SmartScreen warning — click **More info → Run anyway**
4. The widget will appear in your system tray

### Requirements

- Windows 10 / 11 (64-bit)
- A claude.ai account
